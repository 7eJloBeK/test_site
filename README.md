## Структура

```text
/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
└── README.md
```

## Публикация на GitHub Pages
Загрузи все файлы и папки в корень репозитория. Затем открой **Settings → Pages**, выбери **Deploy from a branch**, ветку `main` и папку `/ (root)`, после чего нажми **Save**.

Кнопки Telegram пока ведут на `https://t.me/willi_villi89iip`. При наличии отдельной ссылки на канал замени этот адрес в `index.html`.
